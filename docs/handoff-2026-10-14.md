## Practical notes

- **Switching branches**: the game patch differs between branches, and the build refuses a
  checkout patched by another state ("Dependency checkout has local changes but no matching
  patch-state"). Delete `build-3ds/_deps/legend-of-doom` before building another branch.
- The New 3DS is at **192.168.1.142** now (`.3ds_ftp_ip`). If the game fails while loading
  ZScript, look at `startup.log`'s `app_total`: 64 MB means reboot the console.
- Console state left behind by measurements: `r_ticstability` and `lod3ds_stereo` are archived
  cvars; the test build already starts with `r_ticstability 0`. `lod3ds_gpu_world` is not saved:
  set it each launch (`lod-link.py cvar lod3ds_gpu_world true`).
- Console output into a file: `lod-link.py console 'logfile "sdmc:/3ds/Legend of Doom
  3DS/debug/console.log"'` (an absolute path), then fetch it over FTP. GZDoom's `profilethinkers`
  ticks through its own loop and bypasses the static-thing skip: use `lod3ds_tickprofile`.
- Measuring a spot: `console map MAP01`, `touch 292 8` (ALL), `touch 250 8` (GOD), `console warp
  -4831 -323`, `cvar lod3ds_gpu_world true`, `perf 6`.
